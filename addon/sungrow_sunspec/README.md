# Sungrow SHx SunSpec bridge

Reads measurements from a Sungrow SH-series inverter over Modbus TCP and
provides a read-only SunSpec endpoint and live dashboard. The initial profile
targets the SH25T with SHB storage and is community-derived, not an official
Sungrow map.

[![Add repository to Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FThe-Smartest-Home%2Fsungrow_sht_sunspec)

See the **Documentation** tab after installation for setup, network access,
and register-map details.
